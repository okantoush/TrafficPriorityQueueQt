Smart Ambulance additions
=========================

New files:
- Hospital.h / Hospital.cpp
- HospitalManager.h / HospitalManager.cpp
- hospitals_dataset.csv

Modified files:
- TrafficPriorityQueueQt.pro: added the new .h/.cpp files.
- IntersectionWindow.h/.cpp: added the Smart Ambulance button, emergency dialog, and hospital manager connection.

What was added:
1. Hospitals are still graph nodes generated by the row x column map logic.
2. Hospital counts follow the requested table:
   2x2 -> 1 hospital
   2x3 / 3x2 -> 2 hospitals
   3x3 -> 2 hospitals
   3x4 / 4x3 -> 2 hospitals
   4x4 -> 3 hospitals
3. Each generated hospital node is connected to the road graph.
4. HospitalManager assigns medical-resource data to those generated hospital nodes.
5. The red "Smart Ambulance" button appears in both Simulation and Manual modes.
6. The dialog asks for:
   - emergency type
   - ambulance spawn node
7. It filters hospitals by medical readiness, then runs Dijkstra once from the ambulance spawn node.
8. It chooses the hospital with the lowest:
   drive cost + hospital wait time + overload penalty
9. Clicking "Spawn Ambulance" spawns an emergency ambulance on the selected route and updates hospital resources.

ADS concepts used:
- vector for hospital storage
- unordered_map for O(1) hospital lookup
- bitmasking for O(1) capability checks
- priority_queue for Dijkstra
- graph adjacency through outgoing edges
